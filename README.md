# Freundeskreis China-Xinjiang in Deutschland

静态三语 GitHub Pages 网站包（中文 / English / Deutsch）。无需构建工具。

## 发布前必做

将以下占位符替换成真实信息，然后逐页检查：

- `[姓名]` / `[Full name]` / `[Vor- und Nachname]`
- `[街道与门牌号]`、`[邮编] [城市]`（必须为可送达地址）
- `contact@example.org` 与 `privacy@example.org`
- 章程中的 `[城市]`

尤其应由协会负责人或德国法律专业人士确认：实际代表权限、最终章程、是否有会费/捐款、税务状态和负责的数据保护监管机构。不要在未替换法律页占位符的情况下公开发布。

## GitHub Pages 部署

1. 创建 GitHub 仓库；如要使用根域名 `https://<用户名>.github.io/`，仓库名称必须为 `<用户名>.github.io`。
2. 上传本目录的全部文件。
3. 在 GitHub 仓库的 **Settings → Pages** 中选择从默认分支（root）发布。
4. 等待 GitHub Pages 发布完成后，逐页确认语言按钮、邮件链接及法律信息。

本项目为纯 HTML、CSS 和 JavaScript；`_config.yml` 仅提供 GitHub Pages 的基本站点元数据。
